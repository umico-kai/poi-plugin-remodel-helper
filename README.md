# poi-plugin-remodel-helper / 改造规划

给镇守府的舰娘按**改造状态**分个类，一眼看出谁现在就能改、谁只是差材料、谁等级还不够。

## 功能

- **三色状态标记**（只看「下一段」能不能改）
  - 绿 `いっていいよ` —— 等级达标，材料齐全，随时可以改
  - 黄 `いっていい……ってさ` —— 等级够了，但这一段材料不足
  - 红 `待ってろいよ` —— 还没到改造等级
- **改造链一览**：`吹雪改二 → 吹雪改三 → 吹雪改三護(六式)` 一行显示到终态，中间形态不重复标等级，只在下方显示「还差 N 级（最终 Lv.XX）」
- **材料按段明细**：一行一段，例如「改二 → 改三」和「改三 → 改三護」各自列出消耗；按改造顺序模拟消耗，账号只有 1 张图纸时会正确地把第二段标成不足
- **材料缺口总账**：把每艘船**整条改造链**的需求累加，再与账号持有量比对，不会漏掉「改二補」「改三護」这类追加改造
- **按舰娘实例管理**：标记以船位编号（`#123`）为准，同名舰互不影响；改造、形态转换后标记依然跟着这艘船
- **形态转换舰娘**：多形态舰娘有特殊标记，标记完成后这艘船不再提示

## 安装

已发布到 npm：[poi-plugin-remodel-helper](https://www.npmjs.com/package/poi-plugin-remodel-helper)

**方式一：poi 插件管理**

```
poi → 设置 → 插件管理 → 搜索 remodel → 安装
```

**方式二：命令行**

```
cd %APPDATA%\poi\plugins\node_modules
npm install poi-plugin-remodel-helper
```

装完重启 poi，左侧栏出现「改造规划」。

**方式三：手动解压**

下载 Releases 里的 zip，解压到 `%APPDATA%\poi\plugins\node_modules\`，重启 poi。
